About

Move and resize text, shapes, icons and pictures in your browser.

Local projects stay in this browser. Create a Space to save projects and pictures on the server and share them across browsers.

Use Copy Space link and open the same link in each browser. Anyone with that link can read and edit every project in the Space. Keep the link private.

Space changes appear in other open pages. If another page saved a newer version, reload the saved project or save your work as a copy.

Player and Library start as local projects. Use Projects to switch between them. Each keeps its own edits.

Use Copy HTML to keep a file. Clearing browser data removes saved drafts from this browser. Saved Space projects stay on the server; keep the Space link to open them again.

Free to use. View the code on GitHub.
