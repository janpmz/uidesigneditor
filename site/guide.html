About

Move and resize text, shapes, icons and pictures in your browser.

The main editor opens your Space and saves projects and pictures on the server. On the first visit it creates a Space and brings in any existing local projects. This browser remembers it for your next visit.

Use Copy Space link and open the same link in each browser. Anyone with that link can read and edit every project in the Space. Keep the link private.

Space changes appear in other open pages. If another page saved a newer version, reload the saved project or save your work as a copy.

Player and Library are the first sample projects. Use Projects to switch between them. Each keeps its own edits.

Use Copy HTML to keep a file that works on its own. Clearing browser data removes the remembered Space and local drafts. Saved Space projects stay on the server; keep the Space link to open them again.

Free to use. View the code on GitHub.
